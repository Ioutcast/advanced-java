## Анализ вопросов на собеседовании

Redis в основном имеет следующие типы данных:

-Струны
- Хэши
- Списки
-Наборы
- Сортированные наборы

> Помимо этих 5 типов данных, в Redis также есть bitmap, HyperLogLogs, потоки и т. д.

### Строки

Это самый простой тип, обычный набор и получение, выполняющий простое кэширование KV.

```bash
set college szu
```

### Хэши

Это структура, похожая на карту. Обычно это позволяет кэшировать структурированные данные, такие как объект (при условии, что этот объект не вложен в другие объекты), в Redis, а затем каждый раз, когда кеш читается или записывается, можно манипулировать определенным полем хеша.

```bash
hset person name bingo
hset person age 20
hset person id 1
hget person name
```

```json
(person = {
  "name": "bingo",
  "age": 20,
  "id": 1
})
```

### Списки

Списки — это упорядоченные списки, которые можно использовать разными способами.

Например, вы можете использовать список для хранения некоторых структур данных типа списка, таких как списки поклонников и списки комментариев к статьям.

Например, вы можете использовать команду lrange для чтения элементов в определенном закрытом интервале, а также реализовать запросы по страницам на основе списка. Это отличная особенность. На основе Redis можно реализовать простую высокопроизводительную подкачку. Вы можете делать такие вещи, как раскрывающееся меню Weibo и непрерывный пейджинг. Он имеет высокую производительность и может просматривать страницу за страницей.

```bash
# 0开始位置，-1结束位置，结束位置为-1时，表示列表的最后一个位置，即查看所有。
lrange mylist 0 -1
```

Например, вы можете создать простую очередь сообщений, поместить ее из начала списка и извлечь из хвоста списка.

```bash
lpush mylist 1
lpush mylist 2
lpush mylist 3 4 5

# 1
rpop mylist
```

### Наборы

Наборы — это неупорядоченные коллекции с автоматической дедупликацией.

Закиньте данные, которые нужно дедуплицировать, в систему напрямую на основе набора, и они будут дедуплицированы автоматически. Если вам нужно быстро выполнить глобальную дедупликацию некоторых данных, вы, конечно, можете выполнить дедупликацию и на основе HashSet в памяти jvm, но что, если одна из ваших систем развернута на нескольких машинах? Дедупликация глобального набора должна выполняться на базе Redis.

Вы можете выполнять операции пересечения, объединения и разности на основе множества. Например, для пересечения вы можете объединить списки поклонников двух людей, чтобы увидеть, кто их общие друзья. Верно.

Поместите веера двух больших V в два набора и сделайте пересечение между двумя наборами.

```bash
#-------操作一个set-------
# 添加元素
sadd mySet 1

# 查看全部元素
smembers mySet

# 判断是否包含某个值
sismember mySet 3

# 删除某个/些元素
srem mySet 1
srem mySet 2 4

# 查看元素个数
scard mySet

# 随机删除一个元素
spop mySet

#-------操作多个set-------
# 将一个set的元素移动到另外一个set
smove yourSet mySet 2

# 求两set的交集
sinter yourSet mySet

# 求两set的并集
sunion yourSet mySet

# 求在yourSet中而不在mySet中的元素
sdiff yourSet mySet
```

### Сортированные наборы

Сортированные наборы — это отсортированные наборы, которые дедуплицируются, но могут быть отсортированы. При записи выставляется оценка, и набор автоматически сортируется в соответствии с этой оценкой.

```bash
zadd board 85 zhangsan
zadd board 72 lisi
zadd board 96 wangwu
zadd board 63 zhaoliu

# 获取排名前三的用户（默认是升序，所以需要 rev 改为降序）
zrevrange board 0 3

# 获取某用户的排名
zrank board zhaoliu
```
