### обнаружение регистрации микросервисов

#### Эврика

- Сервер Eureka: предоставляет услуги регистрации услуг. После запуска каждого узла он будет зарегистрирован на Eureka Server.
- Клиент Eureka: упростите взаимодействие с сервером Eureka.

#### Смотритель зоопарка

> ZooKeeper — это централизованный сервис для хранения информации о конфигурации, именования, обеспечения распределенной синхронизации и предоставления групповых услуг.

[Zookeeper](https://github.com/apache/zookeeper) — это централизованная служба для хранения информации о конфигурации, именования, обеспечения распределенной синхронизации и предоставления групповых услуг.

#### Разница между Zookeeper и Eureka

Zookeeper гарантирует CP, Eureka гарантирует AP:

- C: Согласованность данных;
- A: Доступность услуги;
- P: отказоустойчивость службы к сбоям сетевых разделов. Эти три характеристики не могут быть удовлетворены одновременно ни в одной распределенной системе, одновременно могут быть удовлетворены не более двух из них.

### управление конфигурацией микросервисов

Функция: унифицированное управление информацией о конфигурации одного или нескольких сервисов, централизованное управление.

#### [Disconf](https://github.com/knightliao/disconf)

Distributed Configuration Management Platform (платформа управления распределенной конфигурацией) — это общая компонентная/универсальная платформа, ориентированная на управление конфигурацией различных распределенных систем. Он предоставляет унифицированные услуги управления конфигурацией и представляет собой полное унифицированное решение для распределенной конфигурации на основе Zookeeper.

#### [SpringCloudConfig](https://github.com/spring-cloud/spring-cloud-config)

#### [Apollo](https://github.com/ctripcorp/apollo)

Apollo — это центр распределенной конфигурации, разработанный отделом платформы Ctrip. Он может централизованно управлять конфигурацией различных сред приложений и разных кластеров. После изменения конфигурации ее можно передать в приложение в режиме реального времени. Он также имеет стандартизированные разрешения, управление процессами и другие функции и используется в сценариях управления конфигурацией микросервисов.

### вызов микросервиса (протокол)

> Протокол связи

#### Отдых

- Отправлять запросы Rest через HTTP/HTTPS для взаимодействия с данными.

#### РПК

-Удаленный вызов процедуры
- Это протокол для запроса услуг от удаленных компьютерных программ по сети, не требующий знания базовой сетевой технологии. RPC не зависит от конкретного сетевого протокола передачи, доступны все TCP, UDP и т. д.

#### [gRPC](https://www.grpc.io/)

> Высокопроизводительная универсальная платформа RPC с открытым исходным кодом.

Так называемая структура RPC (удаленный вызов процедур) фактически предоставляет набор механизмов, которые позволяют приложениям взаимодействовать друг с другом, а также соответствует модели сервер/клиент. При его использовании клиент вызывает интерфейс, предоставленный сервером, точно так же, как вызов локальной функции.

####РМИ

-Удаленный вызов метода
- Чистые вызовы Java

### Вызов сервисного интерфейса

> Функция: связь между несколькими службами

#### [Feign(HTTP)](https://github.com/OpenFeign/feign)

Все микросервисы Spring Cloud Netflix представлены в виде HTTP-интерфейсов, поэтому их можно вызывать с помощью Apache HttpClient или Spring RestTemplate. Feign — более удобный HTTP-клиент. Это похоже на вызов метода собственного проекта, но без ощущения вызова удаленного метода.

### Сервисный автоматический выключатель

> Функция: когда запрос достигает определенного порога, его продолжение не допускается.

#### [Hystrix](https://github.com/Netflix/Hystrix)

> Hystrix — это библиотека задержки и отказоустойчивости, предназначенная для изоляции точек доступа к удаленным системам, службам и сторонним библиотекам, предотвращения каскадных сбоев и обеспечения устойчивости в сложных распределенных системах, где сбой неизбежен.

#### [Sentinel](https://github.com/alibaba/Sentinel)

> Легкий и мощный компонент управления потоком, обеспечивающий надежность и мониторинг микросервисов. (Облегченное управление потоком, резервная библиотека Java для автоматического выключателя)

### Балансировка нагрузки сервисов

> Функция: снижение рабочего давления и увеличение пропускной способности.

#### [Ribbon](https://github.com/Netflix/ribbon)

> Spring Cloud Ribbon — это инструмент балансировки нагрузки на стороне клиента на основе HTTP и TCP, который реализован на основе Netflix Ribbon.

#### [Nginx](https://github.com/nginx/nginx)

Nginx (движок x) — это высокопроизводительный веб-сервер HTTP и обратного прокси-сервера, который также предоставляет услуги IMAP/POP3/SMTP.

#### Разница между Nginx и Ribbon

Nginx относится к балансировке нагрузки на стороне сервера, а Ribbon — к балансировке нагрузки на стороне клиента. Функции Nginx и Tomcat, функции ленты и вызовы (RPC) между различными сервисами.
