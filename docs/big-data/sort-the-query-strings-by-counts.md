# Как сортировать по частоте запросов?

## Постановка задачи

Всего 10 файлов, каждый размером 1 Гб. В каждой строке каждого файла хранится запрос пользователя. Запрос каждого файла может повторяться. Требуется сортировка по частоте запросов.

## Подход к решению

Если частота повторения запроса относительно высока, вы можете считать все запросы в память для одновременной обработки; если частота повторения запроса невысока, то доступной памяти недостаточно для размещения всех запросов. В это время для решения проблемы необходимо использовать метод «разделяй и властвуй» или другие методы.

### Способ 1: метод HashMap

Если частота повторения запросов высока, это означает, что общее количество различных запросов относительно невелико. Вы можете рассмотреть возможность загрузки всех запросов в HashMap в памяти. Затем вы можете отсортировать по количеству раз появления запроса.

### Способ 2: разделяй и властвуй

Метод «разделяй и властвуй» должен определить размер проблемы на основе размера данных и размера доступной памяти. Для этого вопроса вы можете последовательно просмотреть запросы в 10 файлах и разделить эти запросы на 10 небольших файлов с помощью хэш-функции `hash(query) % 10`. Затем используйте HashMap, чтобы подсчитать количество вхождений запроса для каждого небольшого файла, отсортировать по количеству и записать его в другой отдельный файл.

Затем все файлы сортируются по количеству запросов. Здесь можно использовать сортировку слиянием (поскольку все запросы не могут быть прочитаны в память, необходимо использовать внешнюю сортировку).

## Резюме

- Если памяти достаточно, читаем сразу для сортировки;
- Если памяти недостаточно, сначала разделите ее на небольшие файлы. После того как небольшие файлы будут отсортированы, отсортируйте их и объедините, используя внешнюю сортировку.
