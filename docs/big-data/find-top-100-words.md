# Как найти часто встречающиеся слова в большом объеме данных?

## Постановка задачи

Есть файл размером 1 ГБ. Каждая строка в файле представляет собой слово. Размер каждого слова не превышает 16Б. Ограничение размера памяти составляет 1 МБ. Требуется вернуть 100 наиболее часто встречающихся слов (Top 100).

## Подход к решению

Из-за ограничений памяти мы по-прежнему не можем напрямую прочитать все слова большого файла в память одновременно. Таким образом, вы также можете использовать стратегию **разделяй и властвуй**, чтобы разбить большой файл на несколько маленьких файлов, чтобы размер каждого файла был меньше 1 МБ, а затем напрямую считать один маленький файл в память для обработки.

**Идея заключается в следующем**:

Сначала пройдите по большому файлу, выполните `hash(x) % 5000` для каждого пройденного слова x и сохраните слово, результатом которого является i, в файл a<sub>i</sub>. После обхода мы можем получить 5000 небольших файлов. Размер каждого небольшого файла составляет около 200 КБ. Если размер некоторых небольших файлов по-прежнему превышает 1 МБ, продолжайте разложение таким же образом.

Затем посчитайте 100 наиболее часто встречающихся слов в каждом небольшом файле. Самый простой способ — использовать HashMap. Ключом является слово, а значением — частота слова. Конкретный метод: для пройденного слова x, если оно не существует в карте, выполнить `map.put(x, 1)`; если он существует, выполните `map.put(x, map.get(x)+1)` и добавьте 1 к частоте слова.

Выше мы посчитали частоту слов в каждом небольшом файле. Далее мы можем найти 100 наиболее часто встречающихся слов среди всех слов, сохранив небольшую верхнюю кучу. Конкретный метод: пройтись по каждому небольшому файлу по очереди и построить **маленькую верхнюю кучу** с размером кучи 100. Если количество вхождений пройденного слова больше, чем количество вхождений слова в вершину кучи, замените слово на вершине кучи новым словом, а затем перенастройте его на **маленькую верхнюю кучу**. После завершения обхода слова в маленькой верхней куче будут состоять из 100 слов с наибольшей частотой появления.

## Резюме

1. Разделяй и властвуй, хеширование и остаток;
2. Используйте HashMap для подсчета частот;
3. Чтобы найти **самые большие** элементы TopN, используйте **маленькую верхнюю кучу**; чтобы найти **самые маленькие** элементы TopN, используйте **большую верхнюю кучу**.
