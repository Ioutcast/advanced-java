# Как найти уникальные целые числа в большом объеме данных?

## Постановка задачи

Найдите уникальные целые числа среди 250 миллионов целых чисел. Примечание. Недостаточно памяти для хранения этих 250 миллионов целых чисел.

## Подход к решению

### Способ 1: Разделяй и властвуй

Подобно предыдущему методу вопросов, сначала разделите 250 миллионов чисел на несколько небольших файлов, используйте HashSet/HashMap, чтобы найти уникальные целые числа в каждом небольшом файле, а затем объедините каждый промежуточный результат, что и является окончательным результатом.

### Способ 2: bitmap-метод

**bitmap** использует один или несколько битов для обозначения значения, соответствующего элементу, а ключом является элемент. Использование битов в качестве единиц хранения данных может значительно сэкономить место для хранения.

bitmap представляет наличие или отсутствие определенных элементов с помощью битового массива. Его можно использовать для быстрого поиска, определения веса, сортировки и т. д. Не очень понятно? Позвольте мне сначала привести вам небольшой пример.

Предположим, мы хотим отсортировать 5 элементов (6, 4, 2, 1, 5) в `[0,7]`, мы можем использовать метод bitmap. Всего существует 8 чисел в диапазоне от 0 до 7, для которых требуется всего 8 бит, то есть 1 байт. Сначала установите каждый бит в 0:

```
0 0 0 0 0 0 0 0
```

Затем проходим 5 элементов, сначала встречаем 6, затем устанавливаем 0 бита с индексом 6 в 1; затем встретите 4, установите 0 бита с индексом 4 на 1:

```
0 0 0 0 1 0 1 0
```

После последовательного обхода битовый массив выглядит следующим образом:

```
0 1 1 0 1 1 1 0
```

Для каждого бита, равного 1, его нижний индекс представляет собой число:

```
for i in range(8):
    if bits[i] == 1:
        print(i)
```

Таким образом мы фактически добились сортировки.

Для решения целочисленных алгоритмов **битовый метод** является очень практичным алгоритмом. Если предположить, что целое число int занимает 4B, то есть 32 бита, то количество целых чисел, которые мы можем представить, равно 2<sup>32</sup>.

**Итак, в этом вопросе** мы используем 2 бита для представления статуса каждого числа:

- 00 означает, что этот номер никогда не появлялся;
- 01 означает, что данное число встречается один раз (т.е. неповторяющееся целое число, найденное для вопроса);
- 10 означает, что число появляется несколько раз.

Тогда для этих 2<sup>32</sup> целых чисел общий требуемый объем памяти составит 2<sup>32</sup>\*2b=1 ГБ. Поэтому, когда доступная память превышает 1 ГБ, можно использовать метод bitmap. Предполагая, что память соответствует требованиям bitmap-метод, выполните следующие операции:

Пройдите 250 миллионов целых чисел и проверьте соответствующий бит в bitmap. Если это 00, оно становится 01, если это 01, оно становится 10, а если 10, оно остается неизменным. После завершения обхода проверьте битовую карту и выведите целое число, соответствующий бит которого равен 01.

Конечно, в этом вопросе есть особое примечание: **Памяти недостаточно для размещения этих 250 миллионов целых чисел**. Размер памяти на 250 миллионов целых чисел: 2,5e8/1024/1024/1024 \* 4=3,72 ГБ. Если объем памяти превышает 1 ГБ, проблему можно решить с помощью bitmap-метод.

## Резюме

**Проблема определения повторяемости чисел**. Метод bitmap является очень эффективным методом. Конечно, предполагается, что объем памяти должен соответствовать объему памяти, необходимому для метода bitmap.
