# Как узнать IP-адреса, которые посещают большинство веб-сайтов Baidu в определенный день?

## Постановка задачи

Существующие массивные данные журнала хранятся в очень большом файле, который нельзя напрямую прочитать в памяти. Требуется извлечь IP-адрес, который чаще всего посещал Baidu в определенный день.

## Подход к решению

Этот вопрос касается только IP-адресов, которые чаще всего посещают Baidu в определенный день. Поэтому вы можете сначала просмотреть файл и записать соответствующую информацию об IP-адресах, которые посещают Baidu в этот день, в отдельный большой файл. Далее используется тот же метод, что и в предыдущем вопросе: сначала хэш-карта IP-адресов, затем использование HashMap для подсчета количества повторяющихся IP-адресов и, наконец, вычисление IP-адреса с наиболее повторяющимися IP-адресами.

> Примечание. Здесь вам нужно найти только тот IP-адрес, который появляется чаще всего. Вам не нужно использовать кучу, просто используйте переменную max.

## Резюме

1. Разделяй и властвуй, хеширование и остаток;
2. Используйте HashMap для подсчета частот;
3. Чтобы найти **самые большие** элементы TopN, используйте **маленькую верхнюю кучу**; чтобы найти **самые маленькие** элементы TopN, используйте **большую верхнюю кучу**.
