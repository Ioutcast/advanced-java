# Как найти медиану из 500 миллионов чисел?

## Постановка задачи

Найдите медиану из 500 миллионов чисел. После того, как данные отсортированы, число в середине является медианой. Если количество выборок нечетное, медианой является `(N+1)/2`-е число; когда количество выборок четное, медиана представляет собой среднее значение `N/2`-го числа и `1+N/2`-го числа.

## Подход к решению

Если для этого вопроса нет ограничения на размер памяти, вы можете считать все числа в памяти и отсортировать их, чтобы найти медиану. Но временная сложность лучших алгоритмов сортировки составляет `O(NlogN)`. Здесь используются другие методы.

### Способ 1: метод двойной сваи

Поддерживайте две стопки: большую верхнюю и маленькую верхнюю. Наибольшее число в большой куче меньше или равно наименьшему числу в маленькой куче; гарантируется, что разница в количестве элементов в двух кучах не превышает 1.

Если общее количество данных четное, после построения двух стопок медиана представляет собой среднее значение верхних элементов двух стопок. Если общее количество данных является нечетным числом, в зависимости от размеров двух куч, медиана должна находиться на вершине кучи с большим количеством данных.

```java
class MedianFinder {

    private PriorityQueue<Integer> maxHeap;
    private PriorityQueue<Integer> minHeap;

    /** initialize your data structure here. */
    public MedianFinder() {
        maxHeap = new PriorityQueue<>(Comparator.reverseOrder());
        minHeap = new PriorityQueue<>(Integer::compareTo);
    }

    public void addNum(int num) {
        if (maxHeap.isEmpty() || maxHeap.peek() > num) {
            maxHeap.offer(num);
        } else {
            minHeap.offer(num);
        }

        int size1 = maxHeap.size();
        int size2 = minHeap.size();
        if (size1 - size2 > 1) {
            minHeap.offer(maxHeap.poll());
        } else if (size2 - size1 > 1) {
            maxHeap.offer(minHeap.poll());
        }
    }

    public double findMedian() {
        int size1 = maxHeap.size();
        int size2 = minHeap.size();

        return size1 == size2
            ? (maxHeap.peek() + minHeap.peek()) * 1.0 / 2
            : (size1 > size2 ? maxHeap.peek() : minHeap.peek());
    }
}
```

> См. [LeetCode No.295](https://leetcode.com/problems/find-median-from-data-stream/)

Вышеописанный метод требует загрузки всех данных в память. Это невозможно сделать, если объем данных велик, поэтому этот метод подходит для небольших объемов данных. Чисел 500 миллионов, каждое число занимает 4Б, а памяти всего требуется 2ГБ. Если доступная память меньше 2 ГБ, этот метод использовать нельзя. Другой метод представлен ниже.

### Способ 2: разделяй и властвуй

Идея метода «разделяй и властвуй» заключается в постепенном преобразовании большой проблемы в более мелкие проблемы, которые нужно решить.

Для ответа на этот вопрос прочитайте эти 500 миллионов чисел последовательно. Для номера чтения num, если старший бит в соответствующем двоичном файле равен 1, запишите это число в f1, в противном случае запишите его в f0. Благодаря этому шагу эти 500 миллионов чисел можно разделить на две части, причем числа в f0 больше, чем числа в f1 (старший бит — это знаковый бит).

После разделения очень легко узнать, находится ли медиана в f0 или f1. Предположим, в f1 100 миллионов чисел, тогда в f0 должна быть медиана, и она представляет собой среднее значение 150-миллионного числа f0, расположенного от меньшего к большему, и следующего числа.

> **Совет**: медиана 500 миллионов чисел — это среднее значение 250 миллионного числа, расположенного справа. Если f1 содержит 100 миллионов чисел, то медиана — это среднее значение двух чисел в f0, начиная со 150-миллионного числа.

Для f0 вы можете продолжать делить файл на две части, используя второе по величине двоичное число, и продолжать деление таким образом до тех пор, пока разделенный файл не будет загружен в память. После загрузки данных в память отсортируйте их напрямую, чтобы найти медиану.

> **Примечание**: если общее количество данных четное и если данные в двух файлах после разделения имеют одинаковое число, то медиана представляет собой среднее значение максимального значения в файле с меньшими данными и минимального значения в файле с большими данными.

## Резюме

Разделяй и властвуй, это очень вкусно!
