# Как посчитать количество разных телефонных номеров?

## Постановка задачи

Известно, что файл содержит несколько телефонных номеров, каждый из которых состоит из 8 цифр, и подсчитывается количество различных номеров.

## Подход к решению

Суть этого вопроса заключается в решении проблемы **дублирования данных**. Для задач такого типа в первую очередь обычно рассматривают метод bitmap.

В этом вопросе количество чисел, которые могут быть представлены 8-значным телефонным номером, составляет 10<sup>8</sup>, или 100 миллионов. Если мы используем один бит для представления каждого числа, всего потребуется 100 миллионов бит, а память займет около 12 МБ.

**Идея заключается в следующем**:

Примените массив bitmap длиной 100 миллионов и инициализируйте его значением 0. Затем выполните итерацию по всем номерам телефонов и установите позицию в bitmap, соответствующую номеру, равной 1. После завершения обхода, если бит равен 1, это означает, что номер телефона существует в файле, в противном случае он не существует. Количество битовых значений 1 — это количество разных телефонных номеров.

## Резюме

Чтобы решить проблему дублирования данных, не забудьте рассмотреть bitmap-метод.
